# راهنمای صفحات HTML پلتفرم فریلنسری

این پوشه شامل تمام صفحات HTML برای تست و استفاده از پلتفرم فریلنسری است.

## فایل‌های موجود

### 1. `index.html` - صفحه اصلی
- صفحه اصلی پلتفرم با معرفی ویژگی‌ها
- بخش‌های مختلف شامل قهرمان، ویژگی‌ها، دسته‌بندی‌ها و آمار
- ناوبری خودکار بر اساس وضعیت ورود کاربر

### 2. `register.html` - ثبت‌نام
- فرم ثبت‌نام برای کارجو و کارفرما
- انتخاب نوع کاربر (کارجو/کارفرما)
- فیلد شرکت برای کارفرمایان
- هدایت خودکار به صفحه ورود پس از ثبت‌نام

### 3. `login.html` - ورود
- فرم ورود با ایمیل و رمز عبور
- ذخیره توکن JWT در localStorage
- هدایت خودکار بر اساس نوع کاربر:
  - کارجو → `freelancer-skills.html`
  - کارفرما → `post-job.html`

### 4. `freelancer-skills.html` - ثبت مهارت‌های کارجو
- فرم پویا برای افزودن مهارت‌ها
- انتخاب کلاس و زیرکلاس شغلی
- تعیین سطح تسلط (مبتدی/متوسط/حرفه‌ای)
- حذف و ویرایش مهارت‌ها
- نیاز به احراز هویت

### 5. `post-job.html` - ثبت آگهی کارفرما
- فرم کامل برای ثبت آگهی جدید
- انتخاب نوع بودجه (بازه‌ای/توافقی)
- افزودن مهارت‌های مورد نیاز
- نیاز به احراز هویت

### 6. `jobs.html` - نمایش آگهی‌ها
- نمایش تمام آگهی‌های موجود
- صفحه‌بندی (Load More)
- نمایش جزئیات کامل هر آگهی
- فرمت‌بندی مناسب بودجه و تاریخ

### 7. `dashboard.html` - داشبورد کاربری
- نمایش اطلاعات کاربر
- بخش‌های مختلف برای کارجو و کارفرما
- نمایش مهارت‌های کارجو
- نمایش آگهی‌های کارفرما
- آگهی‌های اخیر
- نیاز به احراز هویت

## نحوه استفاده

### 1. راه‌اندازی سرور
```bash
# در پوشه اصلی پروژه
php -S localhost:8000
```

### 2. دسترسی به صفحات
- صفحه اصلی: `http://localhost:8000/pages/index.html`
- ثبت‌نام: `http://localhost:8000/pages/register.html`
- ورود: `http://localhost:8000/pages/login.html`
- و غیره...

### 3. جریان کاربری

#### برای کارجو:
1. ثبت‌نام در `register.html`
2. ورود در `login.html`
3. ثبت مهارت‌ها در `freelancer-skills.html`
4. مشاهده آگهی‌ها در `jobs.html`
5. مدیریت حساب در `dashboard.html`

#### برای کارفرما:
1. ثبت‌نام در `register.html`
2. ورود در `login.html`
3. ثبت آگهی در `post-job.html`
4. مشاهده آگهی‌ها در `jobs.html`
5. مدیریت حساب در `dashboard.html`

## ویژگی‌های فنی

### احراز هویت
- استفاده از JWT Token
- ذخیره در localStorage
- بررسی خودکار وضعیت ورود
- هدایت خودکار به صفحه ورود

### رابط کاربری
- طراحی RTL برای فارسی
- استفاده از Tailwind CSS
- فونت Vazir
- رابط کاربری واکنش‌گرا

### تعامل با API
- استفاده از Fetch API
- مدیریت خطاها
- نمایش پیام‌های موفقیت/خطا
- بارگذاری و وضعیت‌های مختلف

## نکات مهم

1. **احراز هویت**: تمام صفحات محافظت شده نیاز به توکن معتبر دارند
2. **CORS**: سرور باید CORS را پشتیبانی کند
3. **مسیریابی**: تمام لینک‌ها نسبی هستند و باید از پوشه `pages` اجرا شوند
4. **دیتابیس**: قبل از استفاده، دیتابیس باید راه‌اندازی شده باشد

## عیب‌یابی

### مشکل در اتصال به API
- بررسی آدرس سرور در فایل‌های JavaScript

### مشکل در احراز هویت
